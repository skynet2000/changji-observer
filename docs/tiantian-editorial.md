# 天天HOT 内容配置

> 历史记录：本文保留当时的站名与配置，不代表当前运行状态。网站现名为「大厂观察」；当前操作请参阅维护说明（`docs/maintenance.md`，本目录内为 `maintenance.md`）。

定位：面向互联网大厂员工，国内互联网为主、兼顾海外。核心关注互联网行业与企业发展，包括阿里及各竞争互联网企业的战略、经营、业务布局、竞争和资本动作。普通软件更新、个人工具兴趣和商家经营教程不属于核心资讯。

## 关注什么

- 大厂战略：财报、业务取舍、资源投向、投资并购与竞争格局。
- 组织与人才：有公开证据的组织架构、管理层变化、招聘趋势、薪酬绩效、晋升及工作制度。保留适用范围，过滤匿名爆料与个人隐私。
- 产品与AI：用户入口、产品竞争、研发办公流程与能力边界。
- 电商竞争、本地生活：站在员工理解业务的角度，看平台战略、用户增长、商业化、即时零售与履约效率。
- 职业成长：产品、技术、运营、数据分析、协作管理与AI工作方法，有证据、能复用。
- 深度分析与政策监管：商业模式、组织管理、劳动政策、数据与AI治理等行业环境变化；研究和模型发布作为补充。

主题目录优先展示阿里巴巴、淘宝天猫、阿里云、高德、菜鸟、饿了么、美团、京东、拼多多、字节跳动、小红书等。公司与业务分别识别，不因文章提到阿里就全部归入千问。

## 选稿与写作

没有提及 AI 的互联网新闻也进入相关性预筛。公司名称不自动加分；相关性与事实证据分开评价。同一事件合并，优先解释实际变化及适用条件。

抑制普通促销、厂商营销、无依据传闻、标题党、重复转发和无业务影响的技术微更新。单店投流、选品、开店教程不作为重点。影响平台竞争的补贴机制以及公司级招聘策略不能误当普通促销或岗位广告。经营数字保留报告期、币种、同比/环比和口径：GMV不等于收入，订单不等于用户，补贴不等于利润。

评分仍保留上游的七种内容类型、五个维度和权重、安全边界及数值门槛。改动集中在互联网领域的价值与噪声示例。之后需以站长标注的真实样本校准，尚未用真实模型验证选稿质量。

AI 关键词、大厂名称、创始人履历都不是入选理由。文章核心须有具体的互联网业务、产品入口、经营竞争、资本动作、组织人才或监管联系；不替原文脑补“影响大厂”。独立 AI 公司在互联网应用、云服务等领域的业务竞争仍可纳入。纯科研、模型技术愿景、实验室揭牌、机器人部署、AI 小硬件以及传统商家经营内容，没有上述核心联系则过滤。“全部动态”同样经过相关性筛选，低评分不能代替过滤。

## 全部动态按事件去重（2026-10-13）

千问 N1/N1 Pro 眼镜与耳机的两篇报道已被归入同一 fact，重复展示的原因是“全部动态”此前仍按文章分页。本次让全部动态及两种搜索排序在分页、总数和今日计数之前，按已确认的 fact 折叠。同一公司不同事件、同一事件的实质后续进展有不同 fact，继续独立显示；未确认归属、综合稿、仅提及事件的材料不强行合并。

代表报道在当前筛选/搜索匹配范围内选择：全文相关搜索先看匹配分，其后依次优先已精选、一手来源、内容评分，再按较早时间和稳定 ID 排序。同一次发生按最早可见报道定位，后续转载不顶起旧闻。原始报道、详情链接和收藏记录保留，可点击“2 篇报道”或“另有 N 家信源报道”查看。展开范围沿用频道、分类与标签，包含该事件的其他报道，方便比较搜索命中以外的来源。机器 API 的原始文章列表仍供逐篇检索，精选出口维持原有代表报道机制。
