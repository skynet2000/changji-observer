# 厂际观察的界面设计

2026-10-21，用户选择「现代行业刊物」。面向互联网中大厂职场人，围绕公司发展、组织处境和业务竞争，保持「全部＋四个栏目」。

## 这次的改变

- 桌面恢复左侧分组导航：内容区依次为精选、全部、热点榜、日报、主题与收藏，工具入口放在下方，外观放在侧栏底部；日报入口同时匹配周报和月报。沿用清晰的页面导航逻辑，保留本站品牌、配色和卡片样式。
- 登录与语言在电脑、手机每一页右上角；手机使用底部主导航、信息流顶部的精选/全部切换及筛选面板，“我的”保留收藏、外观与工具入口。登录可选，收藏与已读保持原来的同步规则。新打开或刷新默认中文，EN 必须主动切换，站内跳转保留当前语言。
- 纸白、海军蓝墨色、编辑蓝品牌色；深色模式使用灰蓝和浅蓝。字体使用本机系统字体，不添加远程字体请求。
- 首页缩小刊头，栏目用独立下划线导航，搜索在空间不足时换行。窄桌面和手机保持单列，热点在信息流前；日报归档列相应收窄，避开语言提示。日期仍按北京时间、原文发布时间排列，归组不变。
- 精选/全部切换在桌面与手机都保留栏目、来源频道和标签，不带搜索排序或页码。栏目、频道、标签与搜索独立；改变栏目仅清除分页，标签和频道都有可见取消入口。浏览器返回保留原筛选，已访问页面继续复用有效缓存。
- 新闻卡片取消外置的圆点时间轴，将时间放在来源旁；推荐理由独立成注释块。分数仍是模型分数，不能视为人工事实核查。
- 日报使用可访问的文字刊头，沿用期号、归档、原文与进展；不改历史成刊数据。
- 下拉菜单补上方向键、Home/End、Escape 与焦点返回。触摸目标尽量为 44px，进入和展开保持轻量反馈；减少动态效果偏好会关闭动效。
- 内容译文与界面模板分开查找，避免资讯中的「十」「与」被误当作界面插值。
- 信息流、日报引用、榜单来源与来源名单逐个翻译媒体名，避免把拼接的来源列表当作一段新文本；新信源通过同一公开范围和后台缓存补译。

## 研究来源与素材边界

| 来源 | 借鉴点 | 使用方式 |
| --- | --- | --- |
| [NewsIQ](https://newsiq.xyz/) | 顶部账号入口、阅读层级 | 观察公开页面，本站独立实现 |
| [GSAP Showcase](https://gsap.com/showcase/) | 动效用于反馈、转场与视觉节奏 | 不搬运展示作品、视频与图像；无需新增动画依赖 |
| [MotionSites](https://motionsites.ai/) | 标题层级、组件间距与对比 | 仅视觉研究，不复制收费模板或提示词 |
| [Fusion](https://github.com/0x2E/fusion) | 轻量 RSS 阅读结构 | 查看项目及 [MIT 许可](https://github.com/0x2E/fusion/blob/main/LICENSE)，未复制代码/素材 |
| [NewsNow](https://github.com/newsnext/newsnow) | 新闻导航和榜单组织 | 查看项目及 [MIT 许可](https://github.com/newsnext/newsnow/blob/main/LICENSE)，未复制代码/素材 |
| [Folo](https://github.com/RSSNext/Folo) | 阅读、收藏与来源的层级 | 仅观察；[许可](https://github.com/RSSNext/Folo/blob/dev/LICENSE)含 AGPL 与图标例外，未复制代码或图标 |

改造在现有开源项目基础上进行，保留原有许可证、NOTICE 与必要署名。自有前端样式不改变底层来源，不能删除原项目著作权说明。后续若实际引入第三方素材，应在此记录具体文件、版本和许可。

## 验收范围

浏览器验证窄屏、桌面、中英文、深色与减少动态效果偏好；回归导航、键盘菜单、搜索筛选、归组展开、收藏、账号导入/同步、日报阅读。公开请求只读取已存译文，不触发模型调用。
