# 厂际观察：职场信息覆盖验收（2026-10-18）

## 本轮改动

- 将企业发展与员工处境明确为并列准入依据。全员信、管理要求、组织调整、招聘裁撤、薪酬绩效、竞业与公开职场争议，不要求同时具备技术突破或收入变化。
- 评分继续使用原有五轴、类型权重和信源门槛（T1 60、T1_5 65、T2 76）。不靠加奖励分或降低门槛把八卦推入精选。
- 新增三言科技、鞭牛士两个职场专用来源，每小时读取公开列表，按职场主题过滤后送入行业相关性判断。初次回填最多各 8 篇；原文时间取详情页，摘要与原文链接公开，全文不对外授权转载。
- 公开 HTML 列表支持表单 POST 与行属性 URL 模板。请求仍走既有网络保护，POST 不自动重试。
- 短讯采用已验证的 `.article_wrap > .body` 作为摘要证据，解决小红书全员信等短报道被通用正文长度限制漏掉的问题。
- 新内容沿用正常事件归组，不把转载视为独立确认；报道、爆料、公司回应分别保留归因。未来计划不改写成已完成。

## 已核验的限制

- 三言科技 HTTPS 证书目前过期，官方 HTTP 列表和详情可用，当前使用 HTTP，不关闭 TLS 校验；恢复 HTTPS 待来源修复证书后重新验证。
- 鞭牛士 HTTPS 列表和详情正常。两家均采用站点公开脚本使用的 `/news_list_index` 表单查询，详情地址 `/news/details?id=...`。
- 新增来源的首批候选以组织变动、离职、员工通知与公开争议为主。本轮未找到适合补入的近期大厂裁员报道，不将旧消息作为今日新闻，也不虚构全员信/裁员数量。
- 社媒目前仍以既有公开即刻账号为补充，未接入登录后的脉脉或微信私域内容。
- 精选倾向仍需用户标注真实职场样本后校准；本轮复评不是用户标注的金标验收。
