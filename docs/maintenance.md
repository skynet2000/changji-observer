## 日常需要做什么

网站、数据库与采集任务运行在腾讯云首尔服务器，已启用，不依赖你的电脑；本机旧服务已停止。2026-10-25 起按用户最新要求，每个启用自动信源每 120 分钟采集一次，失败时可能延后；打开网页不会调用模型。试运行头三天每天查看，稳定后每周看一次首页、最近日报和后台的信源/任务/模型费用，留意长时间没更新、失败积压和无关内容和分类错误。不要把后台密码、DeepSeek密钥或SSH私钥发到聊天、截图或GitHub。

源码仓库：[skynet2000/dachang-observer](https://github.com/skynet2000/dachang-observer)（公开），在线站域名为`innews.site`。本文的`YOUR_SERVER_HOST`、目录和SSH文件名均须换成你自己实例的信息。站主生产实例的具体入口留在本机私有运维手册，不随公开仓库分发。网站管理员、Linux系统用户与云平台账号彼此独立，不能混用密码。

自己的后台入口是`你的站点域名/admin`。新实例的后台管理员密码由初始化脚本生成，保存在自己的`.env`，不要拿它尝试登录在线示例站。既有站主私有登录记录只在本机忽略目录，不包含于仓库。

## 登录服务器

在这台Mac的终端执行：

```bash
cd "/path/to/changji-observer"
ssh -i .data/deploy/changji-ed25519 -o IdentitiesOnly=yes -o StrictHostKeyChecking=yes -o UserKnownHostsFile=.data/deploy/known_hosts ubuntu@YOUR_SERVER_HOST
```

SSH私钥应仅保存在你自己的本机私有位置；上面的文件名只是示例。请另存一份到你自己保管的离线加密U盘或不启用云同步的本地密码库；不要上传GitHub。更换电脑时需要安全迁移私钥。出现“主机密钥变化”警告时先核对服务器是否重装，不要直接忽略警告。

当前服务器SSH已关闭密码认证，原密码不能用于SSH。系统账号和密码并没有因此被删除；如以后要改回密码方式，应先保留已验证的密钥会话，再通过腾讯云控制台处理，由你本人完成密码重置。不要直接重装系统，重装会影响网站和数据库。

## 查看状态和日志

登录服务器后执行：

```bash
cd /home/ubuntu/changji-observer/current
sudo docker compose ps
sudo docker compose logs --tail=80 worker
sudo docker compose logs --tail=80 api web
```

网站打不开但服务器可以登录时，先保存错误信息。只重启网页与API可执行 `sudo docker compose restart api web`。worker停止时会等待在途模型请求收尾，请不要强制杀进程或反复重启，避免重复付费。不要执行 `docker compose down -v`，它会删除数据库等持久化数据卷。

## 更新网站

## 每日运营邮件与访问统计

每天北京时间09:00从服务器发送到已确认邮箱，费用与访问统一统计昨天00:00–24:00；电脑关机不影响执行。邮件包含本站估算付费费用、免费通道情况、页面请求、估算UV、热门页面、内容产出及当前故障/积压。PV从2026-10-25 18:24开始、UV从同日21:41开始，分别标注覆盖范围，不补造历史数据。UV不等于准确人数，不保存原始IP，不设置统计Cookie；完整口径与私有状态恢复注意事项见[运营邮件](cost-email.md)。

服务器内故障/恢复检查每5分钟执行；它不能替代独立站外监测，整机失联时不保证发信。09:00发送任务、04:10备份任务和故障检查可用`systemctl list-timers "changji-*"`查看；SMTP接受不等于收件箱实际收妥。

## Google 索引排除报告

`noindex` 邮件需要按网址判断，不能全站删除该标记。账号、收藏、搜索、栏目/标签组合及内容不足的主题页属于有意排除。2026-10-26用户确认：普通资讯只要已经通过准入、具有完整标题摘要且公开，即可自动开放详情索引，不再依赖精选；人工排除仍优先，隔离线索、未准入及缺少摘要的材料不因此开放。事件页、首页和刊物有独立索引规则，站点地图只提交当前可收录的规范网址。

暂停精选时，`/` 的规范地址为 `/all`，站点地图及变更通知只提交 `/all`；恢复精选后两者是不同内容页，分别提交。`node scripts/smoke.ts --base <站点地址>` 现在同时核对主要页面的 HTML/HTTP 索引标记、预期私有页面的 `noindex`，并以两个并发检查站点地图的每个网址：必须返回200、允许收录且只有一个匹配的规范地址。错误的 `noindex`、重定向、404、空站点地图及别名都会让命令失败；CI 与发布后检查共用此命令。这些检查不调用模型。

Google 报告有刷新延迟，允许收录也不保证 Google 实际收录。对于有意排除的网址，不应点击“验证修正情况”来宣称已移除排除规则；只有确认误配并修复后才提交验证。

运营邮件的维护影响说明写在服务器私有 `shared/traffic-notes.json`，格式为 `{"YYYY-MM-DD": ["说明文字"]}`，日期按被统计的北京时间自然日。邮件只附对应日期的备注，访问聚合数字保持原样；缺少此文件时沿用正常统计，备注读取异常会在邮件提示。2026-10-26用户选择保留巡检误计数据并注明影响，不执行此前提出的PV/UV扣减或机器人重分类。

## 备份与恢复

部署配置提供每日北京时间04:10的服务器内备份，保留最近七天的成功副本，包含数据库、上传附件、发布版本及SHA256校验。路径为 `/home/ubuntu/changji-observer/backups/automatic/`。检查命令：

```bash
systemctl status changji-backup.timer
journalctl -u changji-backup.service --no-pager -n 20
```

服务器内备份能应对误改数据，不能应对整台服务器或磁盘丢失。迁移快照另有本机副本；用户2026-10-24选择暂不增加异地存储费用，保留现有备份。自动异地备份暂缓，不新增付费资源。不要把数据库备份放到网页目录或GitHub普通文件里。恢复前先停止worker，再备份当前库，在隔离库验证恢复后才切换。

## 界面维护

桌面采用左侧导航，顶部右侧放登录和语言切换；手机采用底部导航与页内栏目，外观可在“我的”调整。主导航为资讯／热点／日报／我的；栏目首项为综合，后接裁员与招聘、职场与组织、经营与竞争、政策与监管。先判断行业相关性，再按主要事实归类，不为技术教程或普通跑分兜底。样式、素材研究与交互约定见 [设计说明](design.md)。资讯排序、精选标准与历史日报快照不随样式修改。


### 同机其他网站的维护边界

大厂观察的仓库、发布目录、应用与数据库属于本项目，个人主页另行维护。当前仅服务器与 HTTPS 入口共享；共享入口的导入配置与证书卷不得在常规发布中清理。更新本网站时只启动 `web api worker`，不要执行覆盖所有服务的重建命令。个人主页的源码、配置、备份任务和维护记录不放进本仓库；任何共享入口调整须单独核对影响范围。
