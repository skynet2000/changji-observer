# 2026-10-23 信息流 UI 与交互复查

本轮覆盖精选、全部与搜索、热点、事件页、日报和账户入口；检查中文/英文、浅色/深色、320/390/1024/1280/1440 像素布局。真实 OAuth 授权流程未重复执行，源站连通性及全历史事件合并不属于本轮完整验收。

## 已修正

- 桌面左右两栏使用同高标题区、同一卡片起点；1440 宽实测标题 y=361.29、首卡 y=418.29，两侧一致。栏目与搜索均高 42px。
- 热点侧栏标题改为“全站热点”，不暗示跟随左侧栏目筛选。热度挪到标题下方，避免标题挤成窄列；空榜无孤立侧栏。1280 以下使用单栏，手机不再把全站热点插到精选前面。
- 删除重复的筛选按钮与弹窗；分类只有一个直接可见入口。手机五个栏目全部可见，英文可换行；搜索与标签可分别取消，保留其他条件。
- 编辑全文搜索保留原来的全文模式与分类、标签；提示语区分标题摘要搜索与全文搜索。
- 热点页标题先于图表，手机图表缩短。标题来源可换行；热点数量为真实条数，不把空榜写成十条，也不代表整个互联网的热度。
- 日期、相对更新时间、热点统计与核心热点界面文案直接本地中英转换。事件综述使用正文翻译通道，避免数字模板错配。
- 信息流按事件最新进展归日；来源行恢复代表报道自身的原文时间，跨日显示原文月日。旧报道不会再被标成后续进展的发布时间。
- 日报说明保留出刊时选稿快照，避免误以为后来入选的报道会自动补进历史日报。

## 仍需如实说明

- 英文标题、摘要与事件正文依赖后台已生成的翻译。最新或待翻译材料会显示中文及提示；本轮不把这称为全部内容已翻译。
- 模型两次评分仍可能波动；已标注样本回归通过不等于独立准确率验证。历史精选本轮按明确清单回评，未遍历重算所有未精选内容。
- 历史事件归组需要内容级复核，UI 的归组展开通过不等于全历史语义归组完全正确。
- 当前热点趋势可能因部分信源落后显示“暂不比较”；这是数据完整性提示，不应伪造涨跌数值。
- 本轮没有改变防火墙、登录权限或其他用户要求暂停的安全配置。
