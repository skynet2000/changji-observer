# 天天HOT 第二轮信源与内容边界

> 历史记录：本文保留当时的站名与配置，不代表当前运行状态。网站现名为「大厂观察」；当前操作请参阅维护说明（`docs/maintenance.md`，本目录内为 `maintenance.md`）。

核验日期：2026-10-13。站长确认优先国内互联网，同时补充行业媒体和企业官方公告。

## 核心内容

重点是互联网行业发展与企业发展：公司战略、财报、经营数据、业务布局、竞争格局、投资并购、出海，以及相关组织调整和监管。覆盖阿里及各竞争互联网企业。

普通软件版本、个人工具合集、家庭使用指南、消费数码和没有业务联系的技术细节不收录。不能只凭科技媒体、大厂名称或AI/MCP关键词判为相关。

站长指出的Firefox图像格式更新、小众App合集、iOS家长控制三篇已作为负样本。调整预筛后，三篇均返回BLOCK，并通过人工撤下设置从公开出口移除；原始文章和处理记录保留。

官方来源设为T1，媒体来源为T2。网页只展示摘要和原文链接，不开站内全文和全文RSS分发。新源首次自动回填限制为1篇；本轮代表样本按列表实际条目选择，以正常材料入库、模型回执、分析和发布函数处理。未来正式采集仍由框架统一执行。

IT之家、少数派暂作备用，避免泛数码与个人工具流占据采集资源。当前共5个来源启用：以上4个加Alizila；自动采集与持续模型调用总开关仍关闭。

## 未接入的入口

- 36氪原RSS地址返回HTML，未得到有效订阅。
- 虎嗅原RSS地址返回404。
- 京东投资者RSS和拼多多投资者公告页在本机返回403，尚未接入；京东官方博客是独立可用的公开入口，不代表投资者RSS已恢复。
- 腾讯旧 `/zh-cn/articles.html` 地址已失效，改用官网提供的新新闻中心地址。
- TechNode默认及分类RSS超过框架响应大小上限，中文站出现访问验证；使用可读取的英文网页快讯，生成中文摘要。未关闭响应大小限制或尝试跨过验证。

TechNode还包含汽车、半导体与机器人内容，来源名称不保证每篇都相关，必须通过企业发展预筛。来源可读也不代表每篇正文都能取得、长期可用或已独立核实官方陈述。

核验记录和试处理结果在本机 `.data/source-round2/`。本轮仍使用每24小时60次的模型请求上限，没有扩大日常预算或开启无限自动采集。
