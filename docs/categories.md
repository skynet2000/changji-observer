# 阅读栏目与归类边界

2026-10-24 站主确认：**全部｜裁员与招聘｜薪酬与职场｜人事与组织｜经营与资本｜业务与竞争｜政策与监管**。先判断互联网行业与员工相关性，再按主要新增事实确定一个主类。分类不是收录凭证，也不是精选等级。

| 栏目 | 主要新增事实 | 边界 |
| --- | --- | --- |
| 裁员与招聘 | 裁员减岗、编制收缩、招聘冻结、校招社招、外包转岗 | 明确岗位进出或机会变化；普通招聘广告不收录；无减岗证据的组织合并归人事 |
| 薪酬与职场 | 工资奖金、绩效晋升、福利、考勤加班、竞业和个体劳动争议 | 员工工作条件与权益；政府劳动政策归监管，纯技术教程不属于职场 |
| 人事与组织 | 高管任免、核心人才流动、部门拆并、汇报线、管理权责 | 组织关系为主线；若主要事实是裁撤岗位或扩招，归裁员与招聘 |
| 经营与资本 | 整体财报、盈利现金流、融资上市、并购、股权控制和集团战略 | 不是所有大厂报道的兜底，产品增长或市场补贴归业务 |
| 业务与竞争 | 产品、用户增长、商业化、出海、补贴竞争、平台规则、业务公信力争议 | 必须有具体业务事实，普通功能更新、消费推广、模型跑分不自动收录 |
| 政策与监管 | 政府法规、正式监管动作、反垄断、数据治理、劳动政策 | 内部工作制度与个体劳动争议归职场；平台自主规则归业务 |

## 交叉材料

每篇只有一个主类，关联用标签补充。全员信、内部邮件、爆料、争议回应、分析、访谈、研究是内容形式；AI、电商、本地生活和公司名是话题或实体。均不占平级栏目。

- 为发展 AI 裁员归裁员与招聘；合并 AI 团队但未宣布减岗归人事与组织。
- 全员信调薪归薪酬与职场，宣布集团投资归经营与资本；载体不决定栏目。
- 产品用户增长归业务与竞争；集团财报归经营与资本。
- 员工质疑产品测评公正性及公司回应归业务与竞争；举报者的劳动处置是主线时归薪酬与职场。
- 公司改变返岗制度归薪酬与职场；政府劳动法规归政策与监管。
- 传闻明确出处与未证实状态；材料不足等待补全，不用经营与资本或其他兜底。

## 代码与历史兼容

`site/site.ts` 的 `READER_CATEGORIES` 定义六个阅读入口；`industry/taxonomy.ts` 和 `industry/prompts/structure.md` 定义分类边界。精选与全部使用同一映射，分类与精选相互独立。

新增 `jobs`、`workplace`；保留 `career`（人事与组织）、`industry`（经营与资本）、`ai-products`（业务与竞争）、`policy`（政策与监管）。全部既有 key 和 API/RSS 订阅地址仍合法。旧业务细分类在网页并入业务与竞争；旧分析和研究按正文复核，不能整批机械搬到经营与资本。新模型分类只选六个主类，形式与领域保留在标签中。

历史迁移逐篇依据原始材料复核，经 `overrideFields` 写入审计与发布投影，保留分数、精选、原文链接、时间、事件归组与阅读记录。已出刊报告只纠正分类分节元数据，保留选稿及标题、摘要等原快照，不重新生成正文。旧分节名作为历史兼容别名，避免改名后无法纠正旧报告。

模型分类复核不是重新评分，也不能据此声称精选校准通过。执行范围、实测样本与待复核项记录在本次迁移验收文件。
