# 阅读栏目与归类边界

2026-10-25站主确认四栏：**裁员与招聘／职场与组织／经营与竞争／政策与监管**。薪酬与职场、人事与组织合为职场与组织；经营与资本、业务与竞争合为经营与竞争。

| 栏目 | 主要新增事实 | 边界 |
|---|---|---|
| 裁员与招聘 | 岗位进出、裁撤、冻结招聘、校招社招、编制与外包转岗机会 | 没有确认减岗的组织合并不能猜成裁员；普通岗位广告不收录 |
| 职场与组织 | 薪资福利、绩效考勤、员工争议、竞业、任免流动、团队拆并、汇报与管理 | 明确岗位进出优先归裁员招聘；公司产品或资本为主线时不因提到员工而归职场 |
| 经营与竞争 | 财报融资、资本与集团战略、产品、市场、平台规则及竞争、公信力争议 | 必须有实质公司或业务主线，普通硬件评测和技术教程不自动准入 |
| 政策与监管 | 外部政府法规、正式监管、反垄断、数据与劳动政策 | 内部工作制度归职场，自主商业规则归经营；高管建议不等于监管行动 |

先做行业准入，再归类。每篇按主要新增事实确定一类，全员信、爆料、分析、AI、电商与公司名作为标签。保留争议归因与材料不足状态。

## 历史兼容

`site/site.ts` 的 READER_CATEGORIES定义四组。旧网页参数career映射workplace，ai-products及旧业务细分类映射industry。原有ID、收藏、已读和API/RSS地址继续有效；未跨组误分类的历史存储细分类保留，只合并读者入口。新结构抽取只输出jobs/workplace/industry/policy。

历史复核只纠正跨组误分类与确证的无关内容，逐项审计，保留原分数与人工选择；不重新评分，也不覆盖已出刊的标题、摘要和选稿快照。已有刊物可能保留当时分节名称，不据此重新生成整刊。
