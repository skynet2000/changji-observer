# 阅读栏目与归类边界

2026-10-24 站主确认栏目为：**大厂动态／组织人事／业务竞争／政策监管**。栏目数量不是固定约束，当前不增加更多顶层入口。

| 栏目 | 主要新增事实 | 排除的混用 |
| --- | --- | --- |
| 大厂动态 | 公司整体经营、财报盈利、现金流、融资上市、投资并购、股权控制、集团战略 | 不作为所有大厂报道的兜底，具体产品与市场动作归业务 |
| 组织人事 | 裁员招聘、薪酬绩效、工作制度、团队撤并、管理任命、人才流动、用工争议和员工处境 | 不因作者是员工、出现团队或工具能提效而进入 |
| 业务竞争 | 产品、入口、定价、交易机制、商业化、用户增长、补贴和市场扩张、业务公信力争议 | 不因涉及收入就变成集团经营；纯技术细节先经过相关性筛选 |
| 政策监管 | 外部法律规则、监管调查与处罚、反垄断、数据隐私与劳动立法 | 公司考勤等内部制度归组织；平台自主商业规则归业务 |

## 分类方法

每篇只有一个主类，按正文主要新增事实判断；关联公司、领域、文章形式用标签补充。分类独立于精选，站主确认的精选不会因调整栏目被撤销。

- 为发展 AI 裁员，主要动作是裁员，归组织人事。
- 全员信宣布部门合并归组织，宣布集团投资计划归大厂动态；载体不决定栏目。
- 产品用户增长归业务，集团财报归大厂动态；数字或公司名不能代替主线判断。
- 员工质疑测评业务公正性，核心若是产品公信力归业务；若是举报员工的遭遇或劳动关系，归组织。员工发声不是单独的主类。
- 监管要求平台改规则归政策；平台自主调整佣金归业务。
- 组织调整的深度稿仍归组织，外卖竞争的复盘仍归业务，不能因文体进入另一栏。

## 代码与历史兼容

`site/site.ts` 的 `READER_CATEGORIES` 定义阅读入口；细分类与提示词在 `industry/taxonomy.ts`、`industry/prompts/structure.md`。网页筛选与公开读取层共用映射。

原有 `industry`、`career`、`ai-products` 等分类身份不重命名、不删除，API/RSS 的细分类订阅仍保留。`opinion`、`paper` 是历史身份，不再仅因分析或研究形式用于新文章；历史文章需按正文逐篇复核，不能整体机械搬到某个新主题。尚未纠正的历史身份在阅读导航中兼容到大厂动态，旧细分类地址仍可访问。

历史纠正通过既有 `overrideFields` 接口写入审计，并保留人工精选、评分、发布时间、事件归组与阅读记录。原 `opinion` 稿调整主类时保留“深度分析”标签；日报同时识别该标签，避免仅因改类把评论性跟进误当成新的官方动作。报告修订保留当期标题、摘要与编排快照，只更新纠正所需的归类元数据。

本说明不承诺历史内容已经全部复核，也不把模型建议等同于人工确认；执行批次和待处理项应单独记录。
