# 天天HOT 首批真实资讯试运行

日期：2026-10-13（北京时间）

## 结果

- DeepSeek 官方接口连接成功，模型 `deepseek-flash`。密钥只在本机 `.env`。
- Alizila、IT之家、少数派各采集3篇，共9篇。6篇进入全部动态，其中1篇精选；3篇消费硬件内容被过滤。
- 精选为《阿里云2026云栖大会公布全栈AI路线图与全球扩张计划》，75分，原始日期为9月24日。回填内容没有冒充今日新闻。
- 蔡崇信谈开源、达摩院医疗模型、App合集、Firefox更新和iOS儿童安全功能保留在全部动态。
- 首轮预筛误过滤了Firefox与iOS更新；增加“相关性与重要性分开判断”的边界说明后，两篇复测均通过相关性检查，但未达到精选门槛。评分权重和门槛未改。
- 官方来源摘要已对照采集原文核对主体、关键数字以及计划和已发生动作的区别。这不等于独立验证官方宣称的效果。

## 用量和运行边界

36次模型请求，输入125,153 tokens、输出1,996 tokens，包括最小连接验证、首轮处理和两篇复测。实际扣费以DeepSeek控制台为准，接口没有返回人民币实付金额。

请求熔断为每分钟12次、每小时60次、每24小时60次。这是次数上限，不是金额上限。自动采集与持续模型调用仍关闭，仅在手动试运行进程中开启。

本机系统代理为 `http://127.0.0.1:7890`，已通过框架的 `EGRESS_PROXY_URL` 接入，保留公网地址和重定向检查。代理软件停止后需重新检查采集；线上部署不应沿用这台Mac的代理地址。

试运行使用正常采集、分析、发布和回执函数。完成后取消15个已被手动处理完成的重复排队任务，避免后台重复处理。详细记录在本机 `.data/trial-review.json`、`.data/trial-process.log` 和 `.data/trial-recheck.log`。
