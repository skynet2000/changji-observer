## 服务器运行什么

代码先保存在新建的GitHub私有仓库 [skynet2000/changji-observer](https://github.com/skynet2000/changji-observer)，再部署到腾讯云。`.env`、`.data/`、`outputs/`、数据库和原始标注结果不提交；保留上游MIT许可。生产服务器从该仓库取得本站定制代码，不能用上游默认站替代。GitHub私有仓库访问凭据单独管理，不写进镜像或仓库。

初期一台普通 Linux 云服务器运行网页、后端 API、采集/评分/日报任务和 PostgreSQL 数据库。DeepSeek 在其服务端运行，本站后端用已有 API Key 发起请求，不下载模型权重，也不需要 GPU。读者打开网页读取已生成结果，不触发模型调用。服务器账单、DeepSeek API 账单、域名续费和异地备份存储费用分别计算。

4GB 内存是较稳妥的建议，不是已测出的硬性最低要求。为降低成本，当前核验境外 2 核 2GB 候选，系统镜像 Ubuntu 24.04；仍需在 2GB Linux 环境完成内存、队列和响应验收后决定是否适合公开运行。系统盘须容纳镜像、数据库和日志；监测磁盘占用并清理旧镜像和过期备份，不把本机备份永久堆在生产磁盘上。暂不另购 GPU、托管数据库或负载均衡。

官方参考：[DeepSeek API](https://api-docs.deepseek.com/zh-cn/)、[阿里云轻量服务器](https://help.aliyun.com/zh/simple-application-server/product-overview/what-is-simple-application-server)。

### 2GB 适配核查

2026-10-20 本地实际规模：27 个自动源、约 1,030 篇材料、数据库约 75MB，过去 24 小时发现 251 篇材料；首次查询无待分析或分析失败材料。随后的查询有 3 个正常运行中的分析任务。任务队列表中的失败记录为旧记录：日报最新失败发生在 10 月 18 日修复前、采集任务失败在 10 月 19 日，不把历史记录当作当前处理积压。证据：`outputs/2GB部署负载核查-20261020.json`。

初步判断：适合按小范围试运行候选推进，当前数据存储量小且模型由 API 提供。未知项仍是目标环境的峰值内存和真实访问量；没有做过 2GB Linux 压测，不能承诺并发人数或日访问量。网页、API、worker、数据库均需计入内存；网页构建、源站详情解析和分享图生成也可能出现峰值，不能只看平时空闲占用。

购机后的放行检查：在首次导入、连续采集和网页访问同时进行时记录峰值内存、交换空间、容器重启、队列最老等待时间和请求错误；验证本小时新任务能在下一轮前正常消化、网页没有持续超时或内存不足退出。构建若资源不足，改用事先构建的 Linux 镜像，不能因服务已启动便跳过构建/升级验收。3Mbps 为全站共享的出口带宽，突然集中访问仍可能变慢；实际放量前再次压测。调整资源或配置前核对活动资格和续费价格变化。

## 目标环境配置与顺序

使用当前修改后的项目，不重新克隆祖宗仓库替代它。为生产单独创建 `.env`、管理员密码、会话签名、图片签名和数据库凭据。现有本地 `.env` 保持 localhost；现在不把本地站点地址改成尚未接通的域名。

生产中使用这些现有配置项：

```dotenv
SITE_URL=https://innews.site
SITE_DOMAIN=innews.site
PORT=127.0.0.1:3000
TRUST_PROXY=true
COLLECT_ENABLED=false
MODEL_CALLS_ENABLED=false
```

这不是完整环境文件，也不包含密钥。2026-10-23 用户已确认正式运行长期不限模型金额，每小时采集；仍保留费用记录、请求频率与并发保护。第一次迁移时关闭采集与模型调用，恢复数据库、附件及现有源配置，检查模型凭据后再开启。避免本地和线上同时重复处理同一批任务。

顺序：确认境外报价、国内网络及购买条款 → 用户购买服务器 → 安装 Docker/迁移应用和数据 → 配置异地备份与告警 → 配置域名解析及 Caddy HTTPS → 真实域名 smoke/权限/重启恢复/费用验收 → 小范围开放。

数据库/API 不对公网开放；SSH 仅允许管理来源；3017 标注服务、`.env`、`.data`、原始标注文件均不发布。是否增加 `www.innews.site` 跳转，后续在实际 DNS/HTTPS 配置时统一处理。

完整待办与既有验收见 [上线执行清单](launch-checklist.md) 和 [2026-10-20 本地复查](prelaunch-review-20261020.md)。
