# 双端阅读布局调整（2026-10-24）

以 AIHOT 手机端的阅读顺序为参考：紧凑顶部、热点在上、按日期的单列阅读、底部导航。品牌、配色与热点样式保留厂际观察自己的设计；不复制参考站 Logo 或内容。

- 精选桌面移除右侧热点栏和上下文说明，热点前三移到信息流上方，完整榜单继续可达；热点范围仍为全站，不能暗示跟随栏目筛选。
- 桌面限制阅读宽度、收紧宣传区，热点和正文同一边线。热点采用蓝青色细线和轻量悬浮反馈；尊重减少动效设置。
- 手机不再堆叠两个顶部工具栏，搜索进入品牌栏；栏目为单行横向滚动，当前栏目自动保持可见，不影响整页滚动。长英文允许标签轨道横向滑动，不撑宽页面。
- 手机信息流使用细分隔线，减少卡片和推荐理由的重复容器；触摸入口与底部导航保留足够点击区域。
- 日期标题吸顶位置随实际工具栏高度变化，普通信息流与全文搜索各自正确。
- 手机完整热点榜直接显示紧凑排名列表，桌面保留大卡与走势图；日报长头条在手机使用更合适的字号。

验证包括 320/390/768/1280/1920 宽度、账户入口、热点位置、单工具栏、无整页横向溢出、栏目和搜索条件保持。模型主备策略不因本次 UI 改动变化。
